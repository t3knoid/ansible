## 📖 Overview
Installs and configures Hashicorp Vault

## 📋 Requirements
- Minimum Ansible version: `2.9`
- Supported on: `Ubuntu` (22.04, 24.04)
- Supported on: `Debian` (11, 12)

- Update apt cache
